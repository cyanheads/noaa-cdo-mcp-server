# 0.1.0 — 2026-05-23

## Added

- `noaa_list_datasets` — list available CDO datasets (GHCND, GSOM, GSOY, NORMAL_*, PRECIP_*) with temporal coverage
- `noaa_list_data_categories` — list measurement category groups (Temperature, Precipitation, Wind, etc.)
- `noaa_list_data_types` — list specific measurement labels (TMAX, TMIN, PRCP, SNOW, etc.) by dataset or category
- `noaa_find_locations` — search geographic locations by category (states, cities, counties, zip codes, climate regions)
- `noaa_find_stations` — search weather stations by location, bounding box, dataset, and data type
- `noaa_get_station` — fetch full metadata for a single station by ID
- `noaa_fetch_data` — fetch historical observation records with date range validation and unit selection
- `noaa://datasets` resource — all CDO datasets as injectable context
- `noaa://stations/{stationId}` resource — station metadata by ID
- `CdoService` — HTTP client with retry, backoff, and camelCase→lowercase parameter translation
- `NOAA_CDO_TOKEN` env var for API authentication (free token at ncdc.noaa.gov/cdo-web/token)
