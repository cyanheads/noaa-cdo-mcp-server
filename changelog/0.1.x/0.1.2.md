# 0.1.2 — 2026-05-23

## Fixed

- **`noaa://stations/{stationId}`** — NOAA CDO returns HTTP 200 with an empty object for unknown station IDs. The resource handler now checks `!station.id` and throws `notFound()` with an actionable recovery hint ([#1](https://github.com/cyanheads/noaa-cdo-mcp-server/issues/1)).
