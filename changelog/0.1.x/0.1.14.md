# 0.1.14 — 2026-06-12

## Added

- **`scripts/clean-mcpb.ts`**: post-pack bundle cleaner wired into the `bundle` script — runs `mcpb clean` then strips dependency-shipped agent docs (`skills/`, `.claude/`, `.agents/`, stray `SKILL.md`) nested under `node_modules/`, which root-anchored `.mcpbignore` patterns cannot reach.
- **`lint:packaging`**: bundle-content and identity checks — `.mcpbignore` dev-dir patterns must be root-anchored (an unanchored `skills/` also strips `node_modules/x/skills/`), built `.mcpb` bundles must carry zero `node_modules` agent-doc entries, and `createApp()` `name`/`title` plus manifest `display_name` must equal the unscoped package name.
- **`check-framework-antipatterns`**: rule 4 flags `z.coerce.boolean()` on env flags (`Boolean("false")` is `true`, so the flag can't be disabled) — pointing to `z.stringbool()`; comment lines are skipped so docs naming a pattern don't false-positive.
- **`Dockerfile`**: `HEALTHCHECK` probing `/healthz` and an `org.opencontainers.image.version` label fed by the `APP_VERSION` build arg.
- **`techniques` skill**: catalog of reusable response/data-shaping patterns.

## Changed

- **`createApp()`**: sets explicit `name` and `title` of `noaa-cdo-mcp-server`, pinning the served identity to the unscoped repo name on every surface.
- **`.codex-plugin/plugin.json`**: `interface.displayName` `@cyanheads/noaa-cdo-mcp-server` → `noaa-cdo-mcp-server`.
