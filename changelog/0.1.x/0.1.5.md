# 0.1.5 — 2026-05-23

## Changed

- **`package.json` scripts** — all `tsx` invocations replaced with `bun run`; `start` removed in favor of explicit `start:stdio`/`start:http`; `start:stdio`/`start:http` now invoke `bun ./dist/index.js` directly; `format` drops the `--unsafe .` target to plain `--unsafe`; `test` uses `bunx vitest run`.
- **`package.json` files** — `changelog/`, `AGENTS.md` removed from published files list (changelog source files not needed by consumers).
- **`package.json` devDependencies** — `tsx ^4.22.3` removed (replaced by `bun run` in all scripts).
- **`.env.example`** — restructured with section headers and explicit values mirroring the full framework env var surface (transport, session, logging, HTTP, auth, NOAA CDO, storage, OTel).
- **`.gitignore`** — aligned to current template: OS, IDE, language-specific, build, package, logs, test coverage, cache, env, and MCP registry sections expanded.
- **`.mcpbignore`** — `.agents/` added to exclusion list.
- **`Dockerfile` LABEL** — `image.title` updated to `@cyanheads/noaa-cdo-mcp-server`; `image.description` shortened to match condensed tagline; label order: title → description → licenses → source.
- **`server.json`** — `MCP_PUBLIC_URL` environment variable entry added to HTTP package.
- **`manifest.json`** — `author`, `runtimes`, and `args` fields reformatted (expanded JSON style, no functional change).
