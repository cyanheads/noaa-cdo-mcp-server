# 0.1.15 — 2026-06-20

Framework maintenance only — no tool, resource, or behavior changes.

## Added

- **`scripts/check-dependency-specifiers.ts`**: new devcheck step (`Dependency Specifiers`, `--no-dep-specifiers`) that hard-fails on floating specifiers (`latest`, `*`, pre-release dist-tags) in `package.json`'s dependency sections and `bun.lock`'s `workspaces` map. Static and local — runs in the default and `--fast` passes. ([cyanheads/mcp-ts-core#246](https://github.com/cyanheads/mcp-ts-core/issues/246))
- **`lint:packaging` plugin-manifest checks**: validates `.claude-plugin/plugin.json`, `.codex-plugin/plugin.json`, and `.codex-plugin/mcp.json` — non-empty descriptions, unscoped machine name in display fields, full `package.json` name in the `npx -y` install arg. Gated by the new `devcheck.config.json` `packaging.pluginManifests` flag (on); the `devcheck` Packaging gate now also runs when a plugin manifest is present. ([cyanheads/mcp-ts-core#240](https://github.com/cyanheads/mcp-ts-core/issues/240))

## Changed

- **Synced framework scripts** — `build-changelog.ts`, `check-framework-antipatterns.ts`, `check-skill-versions.ts`, `devcheck.ts`, `lint-packaging.ts` re-synced to the 0.10.7–0.10.9 framework: fresh-scaffold devcheck guards (changelog sync and git-dependent checks skip without `.git`), and a `check-skill-versions` worktree-deletion guard. ([cyanheads/mcp-ts-core#242](https://github.com/cyanheads/mcp-ts-core/issues/242), [#243](https://github.com/cyanheads/mcp-ts-core/issues/243), [#237](https://github.com/cyanheads/mcp-ts-core/issues/237))

([cyanheads/mcp-ts-core#239](https://github.com/cyanheads/mcp-ts-core/issues/239), [#233](https://github.com/cyanheads/mcp-ts-core/issues/233))
