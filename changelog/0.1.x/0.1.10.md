# 0.1.10 — 2026-05-30

## Changed

- **`noaa_list_datasets`** — `enrichment` block added: `totalCount` (total matching datasets before page limit), optional `notice` (empty-result guidance suggesting filter removal).
- **`noaa_list_data_categories`** — `enrichment` block added: `totalCount`, optional `notice` (empty-result guidance suggesting filter removal).
- **`noaa_list_data_types`** — `enrichment` block added: `totalCount`, optional `notice` echoing `datasetId`/`datacategoryId` filters with concrete alternatives.
- **`noaa_find_locations`** — `enrichment` block added: `totalCount`, optional `notice` echoing `locationCategoryId`/`datasetId` filters with broadening suggestions.
- **`noaa_find_stations`** — `enrichment` block added: `totalCount`, optional `notice` echoing `locationId`/`datasetId`/`datatypeId`/`extent` filters with broadening suggestions.
- **`noaa_fetch_data`** — `enrichment` block added: `totalCount`, `effectiveQuery` (dataset, date range, units, and applied station/location/datatype filters), optional `notice` (empty-result guidance with next-step suggestions). `noaa_get_station` and count/discovery tools are unaffected.
- **`format` script** — split into `format` (`biome check --write .`) and `format:unsafe` (`biome check --write --unsafe .`) to avoid silent unsafe transforms on plain `bun run format`.

## Dependencies

- `@cyanheads/mcp-ts-core` `^0.9.13` → `^0.9.16`
