# 0.1.3 — 2026-05-24

## Changed

- **`noaa_get_station`, `noaa_find_stations`, `noaa_fetch_data`, `noaa_list_datasets`, `noaa_list_data_categories`, `noaa_list_data_types`, `noaa_find_locations`** — `metadata.offset` description corrected from "Zero-based" to "1-based … as returned by the NOAA CDO API."

## Fixed

- **`noaa_get_station`** — NOAA CDO returns HTTP 200 with an empty object for unknown station IDs; handler now checks `!st.id` and throws `ctx.fail('not_found', …)` before attempting to read fields from the empty response.
- **`noaa://stations/{stationId}`**, **`noaa://datasets`** — resource handlers were double-encoding responses via `JSON.stringify`; corrected to return the plain object so the framework serializes once.
