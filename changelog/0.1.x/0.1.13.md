# 0.1.13 — 2026-06-08

## Fixed

- **`noaa_fetch_data`**: unknown `datasetId` now surfaces `validation_error` with a recovery hint pointing to `noaa_list_datasets` instead of a raw HTTP 500. NOAA CDO returns 500 for unrecognized dataset IDs; a `KNOWN_DATASETS` set (all 11 stable datasets, including `NEXRAD2`/`NEXRAD3`) is validated client-side before the request. ([#13](https://github.com/cyanheads/noaa-cdo-mcp-server/issues/13))
- **`noaa_get_station`**: `not_found` error now carries a `Recovery:` line (`Verify the station ID format… use noaa_find_stations`) — the hint was declared in the error contract but not forwarded at the throw site. ([#14](https://github.com/cyanheads/noaa-cdo-mcp-server/issues/14))
- **`noaa_find_locations`**: corrected `ST` location count from `~52` to `51` (50 states + DC) in both the tool description and `locationCategoryId` field `.describe()`. ([#16](https://github.com/cyanheads/noaa-cdo-mcp-server/issues/16))
- **`noaa_list_data_categories`**: corrected total category count from `~41` to `42` in the tool description. ([#16](https://github.com/cyanheads/noaa-cdo-mcp-server/issues/16))

## Changed

- `@types/node` `^25.9.1` → `^25.9.2`
