# 0.1.7 — 2026-05-24

## Fixed

- **Pagination offset** — `buildParams` in `cdo-service.ts` now converts 0-based client `offset` to 1-based before sending to the NOAA CDO API (fixes [#4](https://github.com/cyanheads/noaa-cdo-mcp-server/issues/4)).
- **Dead `no_results` error contracts** — removed unused `no_results` entries from `noaa_fetch_data`, `noaa_find_locations`, `noaa_find_stations`, `noaa_list_data_categories`, and `noaa_list_data_types`; handlers never throw that reason (fixes [#5](https://github.com/cyanheads/noaa-cdo-mcp-server/issues/5)).
