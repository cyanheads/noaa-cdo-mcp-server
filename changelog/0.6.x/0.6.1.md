# 0.6.1 — 2026-08-18

## Added

- **`rate_limited`** reason declared and routed on all eight CDO-backed tools, for a throttled `NOAA_CDO_TOKEN` (`JsonRpcErrorCode.RateLimited`). Kept separate from `service_unavailable` since the recovery differs — pace requests down rather than retry unchanged. ([#28](https://github.com/cyanheads/noaa-climate-mcp-server/issues/28))

## Fixed

- **`service_unavailable`** is now actually emitted on all eight CDO-backed tools. Every catch keyed on `JsonRpcErrorCode.InvalidParams` alone, so a status-mapped 502/503, CDO's own HTML-interstitial throw, and a network-level failure never reached the declared reason. Both are now routed through a shared `upstreamOutageReason()` predicate (`src/mcp-server/tools/definitions/shared/upstream-availability.ts`). ([#28](https://github.com/cyanheads/noaa-climate-mcp-server/issues/28))
