# 0.6.2 — 2026-08-24

## Changed

- **MCP SDK v2** serves protocol revision 2026-07-28 on HTTP endpoints while retaining the initialize-negotiated 2025-era compatibility path.
- **Tool wire contracts** reject undeclared root input keys by name and advertise the structured error envelope, so validating clients accept tool failures.
- **HTTP session mode** is explicitly stateless across the container and documented source configuration.
- **Request context propagation** passes the complete framework context into downstream retry operations, preserving correlation and authentication fields.
- **Bun 1.4 builds** pin both container stages and select the builder's native platform for reliable multi-architecture images.
- **Project tooling** syncs the framework's skills, MCP definition and packaging linters, published changelog files, and MCPB author metadata.
